## What is pages·dev?

pages·dev is a minimal publishing platform. Write in Markdown or HTML, get a clean URL. No build step, no config files — just write and share.

## Create an account

Click **Get started** on the landing page, enter your name, email, and a password. You're in.

## Your first page

1. Once signed in, click **New Page** from the dashboard.
2. Give it a title and slug.
3. Write your content in Markdown or HTML.
4. Toggle **Public** to make it visible.
5. Click **Save**.

Your page is live at `/p/your-slug` instantly.

## Content types

**Markdown** is the default. GitHub Flavored Markdown is supported — tables, task lists, code blocks with syntax highlighting, and more.

**HTML** is also supported. Use it when you need full control over the rendered output.
