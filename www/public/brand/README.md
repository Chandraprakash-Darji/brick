# Brick brand assets

The approved angular knot is the published Brick identity.

- `logo.svg`: canonical editable logo; two vector paths, transparent background, near-black fill.
- `logo.png`: original generated raster reference, with transparency.
- `guidelines.html`: HTML/CSS printable guide with inline vector diagrams, clear space, size samples, palette, and usage rules.
- `mockups/`: stationery, laptop sticker, and apparel concepts.
- `brand-kit.zip`: downloadable package of these assets.

The website's `/brand` page presents these assets. Shared logo components and the favicon use `/brand/logo.svg`.

## Usage

Keep the symbol's proportions, orientation, joins, and negative-space openings intact. Clear space is at least one-quarter of visible symbol width on every side. Recommended minimum digital width is 24 px of visible symbol. Use #171716 on #F5F5F3, or white on near-black. Avoid stretching, rotation, outlines, gradients, or shadows on the mark.

Construction guides are a proposed geometry study. Mockups illustrate physical applications and are not production artwork. Mockup images were made with built-in imagegen; the logo SVG traces the approved raster. The website guidelines use React components, CSS, and inline SVG diagrams. The printable guide uses the same approved vector paths.
