The `brick gen` command generates verified client contract modules and OpenAPI 3.1 specifications directly from your application's schema definitions.

## Generating Client Contracts (`brick gen client`)

To maintain complete bundle isolation between browser applications and backend servers, configure `client` in `Brick.app()`:

```ts title="src/app.ts"
import { Brick } from "@brickkit/core";
import { usersService } from "./services/users";
import { Layer } from "effect";

export default Brick.app({
  services: [usersService],
  layer: Layer.empty,
  client: {
    module: "./contract",
    exportName: "Api",
  },
});
```

Run the generator:

```bash
brick gen client src/app.ts --output src/_brick/contract.ts
```

### Verification and Safety

Before writing the output file, `brick gen client`:

1. Resolves `client.module` relative to your application entry.
2. Dynamically loads the schema module and verifies it exports an `HttpApi` instance.
3. Compares the browser contract's OpenAPI paths and schemas with the running server application's routes.
4. If schemas differ or routes drift, the generator throws an error and aborts.

The generated file re-exports the verified `api` contract and client constructors:

```ts title="src/_brick/contract.ts"
// Generated by Brick. Do not edit.
import { "Api" as api } from "../contract";
import type { HttpApiClient } from "effect/http-api";
export { api };
export { createClient, createEffectClient } from "@brickkit/client";
export type AppClient = HttpApiClient.ForApi<typeof api>;
```

## Generating OpenAPI Specifications (`brick gen openapi`)

Export an OpenAPI 3.1 specification JSON file from your application:

```bash
brick gen openapi src/app.ts --output openapi.json
```

The CLI inspects your application's `HttpApi` and serializes the complete API schema—including input/output structures, tagged error response envelopes, descriptions, and summaries.

## Options Table

| Flag       | Argument  | Default                               | Description                                             |
| :--------- | :-------- | :------------------------------------ | :------------------------------------------------------ |
| `<entry>`  | File path | _(Required)_                          | Application entry file default-exporting a `Brick.app`. |
| `--output` | File path | `openapi.json` / `_brick/contract.ts` | Destination output file for the generated artifact.     |
