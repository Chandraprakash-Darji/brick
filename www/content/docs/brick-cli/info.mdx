---
title: Architecture Inspection
description: Inspect services, action routes, and metadata in an Effect-native application.
---

The `brick info` command inspects an application entry file and exports its complete runtime architecture as structured JSON.

## Usage

Run `brick info` against your application entry:

```bash
bunx brick info src/app.ts
```

Output:

```json
{
  "version": 2,
  "target": "effect-http-api",
  "services": [
    {
      "name": "pages",
      "actions": [
        {
          "name": "list",
          "method": "POST",
          "path": "/api/pages/page/list"
        },
        {
          "name": "get",
          "method": "POST",
          "path": "/api/pages/page/get"
        }
      ]
    }
  ],
  "routes": [
    {
      "service": "pages",
      "name": "list",
      "method": "POST",
      "path": "/api/pages/page/list"
    }
  ]
}
```

## Using with AI Coding Agents

When equipping AI coding agents (such as Claude Code, Cursor, or Copilot) with context about your application, save the architecture JSON:

```bash
bunx brick info src/app.ts > brick-architecture.json
```

Agents can read this file to understand all registered services, available actions, and HTTP endpoint paths without parsing complex server code.
