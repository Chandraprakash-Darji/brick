---
title: Build & Bundling
description: Bundle default-exported Brick applications into standalone Bun server bundles.
---

The `brick build` command bundles a default-exported `Brick.app` into a standalone Bun production server bundle and emits the native application route manifest.

## Minimal Example

Create an application entry that default-exports a `Brick.app` instance:

```ts title="src/app.ts"
import { Brick } from "@brickkit/core";
import { Layer } from "effect";
import { usersService } from "./services/users";

export const app = Brick.app({
  services: [usersService],
  layer: Layer.empty,
  docs: { path: "/reference" },
});

export default app;
```

Bundle the application:

```bash
brick build src/app.ts --outdir dist/brick
```

Output:

```text
Bundled 1 services / 1 routes
Manifest: dist/brick/brick-ir.json
Server:   dist/brick/server.js
```

Run the compiled server with Bun:

```bash
PORT=8080 bun dist/brick/server.js
```

## Options Table

| Flag       | Argument       | Default        | Description                                                                     |
| :--------- | :------------- | :------------- | :------------------------------------------------------------------------------ |
| `<entry>`  | File path      | _(Required)_   | Application entry file. Must default-export a `Brick.app` instance.             |
| `--outdir` | Directory path | `"dist/brick"` | Target output directory for compiled bundles and IR artifacts.                  |
| `--port`   | Number         | `4000`         | Default listening port baked into the server launcher (overridable via `PORT`). |

## Output Bundle Structure

The compilation produces three artifacts in the output directory:

```text
dist/brick/
├── server.js          # Standalone Bun server entry with graceful shutdown
├── server.js.map      # External source map for debugging
└── brick-ir.json      # Serialized intermediate representation of all services and routes
```

### Production Features of the Bundle

The generated `server.js`:

- Uses Bun's native bundler (`target: "bun"`, `format: "esm"`).
- Automatically initializes the application with `await app.ready()`.
- Serves HTTP requests via `Bun.serve`.
- Handles `SIGINT` and `SIGTERM` signals, stopping the server and executing `await app.dispose()` for graceful cleanup.

### The Intermediate Representation (`brick-ir.json`)

`brick-ir.json` contains a structured manifest of the application architecture:

```json
{
  "version": 2,
  "target": "effect-http-api",
  "services": [
    {
      "name": "users",
      "actions": [
        {
          "name": "getUser",
          "method": "POST",
          "path": "/api/users/getUser"
        }
      ]
    }
  ],
  "routes": [
    {
      "service": "users",
      "name": "getUser",
      "method": "POST",
      "path": "/api/users/getUser"
    }
  ],
  "diagnostics": []
}
```

This JSON file is designed for CI validation, deployment checks, and AI agent architecture introspection.
