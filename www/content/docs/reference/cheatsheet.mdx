A quick reference for packages, functions, types, and CLI commands in Brick-TS.

## Core Runtime (`@brickkit/core`)

| Export                          | Kind     | Description                                                                             |
| :------------------------------ | :------- | :-------------------------------------------------------------------------------------- |
| `Brick.action(name, path, s)`   | Function | Constructs an action contract and implementation factory.                               |
| `Brick.endpoint(name, m, p, s)` | Function | Constructs a typed HTTP endpoint with separate `params`, `query`, `payload`, `headers`. |
| `Brick.service(name, opts)`     | Function | Defines an immutable service boundary grouping actions.                                 |
| `Brick.app(options)`            | Function | Assembles services, layers, custom routes, OpenAPI docs, and transports into an app.    |
| `Brick.route(method, path, h)`  | Function | Defines a raw HTTP route handler for health checks or webhooks.                         |
| `Brick.compileService(svc)`     | Function | Compiles an immutable service into an Effect `HttpApiBuilder` layer.                    |
| `Brick.layer(svc)`              | Function | Generates a complete standalone router layer for a single service.                      |
| `secret(name, options?)`        | Function | Declares an environment secret reference resolved lazily.                               |
| `resolveSecrets()`              | Function | Eagerly validates and resolves all declared secret references.                          |
| `isNativeBrickApp(val)`         | Function | Type guard checking if an object is a native Brick application instance.                |

## Contracts & Errors (`@brickkit/core/contracts`)

| Export                  | Kind     | Status | Description                                                           |
| :---------------------- | :------- | :----- | :-------------------------------------------------------------------- |
| `action(name, path, s)` | Function | —      | Browser-safe schema action contract factory without runtime handlers. |
| `endpoint(...)`         | Function | —      | Browser-safe schema endpoint contract factory for REST methods.       |
| `BadRequest`            | Class    | 400    | Standard error for invalid client input or parameters.                |
| `Unauthorized`          | Class    | 401    | Authentication required or token missing/invalid.                     |
| `Forbidden`             | Class    | 403    | Caller lacks permission for the requested action.                     |
| `NotFound`              | Class    | 404    | Requested resource does not exist.                                    |
| `Conflict`              | Class    | 409    | Uniqueness or resource conflict error.                                |
| `InternalServerError`   | Class    | 500    | Unhandled server failure.                                             |

## CRUD Engine (`@brickkit/crud`)

| Export                                   | Kind     | Description                                                                           |
| :--------------------------------------- | :------- | :------------------------------------------------------------------------------------ |
| `crudContract(options)`                  | Function | Constructs a declarative CRUD contract for a Drizzle table with field policies.       |
| `crud(options)`                          | Function | Direct factory generating implemented CRUD handlers.                                  |
| `sqliteStore(table, DbService)`          | Function | Creates a Drizzle store implementation for SQLite databases.                          |
| `postgresStore(table, DbService)`        | Function | Creates a Drizzle store implementation for PostgreSQL databases.                      |
| `database<Self>()(name, effect)`         | Function | Generic factory generating a scoped `Context.Service` and `Layer` for custom handles. |
| `sqliteDatabase<Self>()(name, config)`   | Function | SQLite service/layer factory over the Effect SQL driver (for `sqliteStore`).          |
| `postgresDatabase<Self>()(name, config)` | Function | PostgreSQL service/layer factory over the Effect SQL driver (for `postgresStore`).    |
| `InvalidInput`                           | Class    | Status 400 error for CRUD filter or policy violations.                                |
| `DatabaseFailure`                        | Class    | Status 500 error for database query failures.                                         |

### REST Route Format

| Operation | HTTP Method | Route Format             | Request Mapping                     |
| :-------- | :---------- | :----------------------- | :---------------------------------- |
| `list`    | `POST`      | `/api/resource/query`    | `payload: query`                    |
| `findOne` | `POST`      | `/api/resource/find-one` | `payload: query`                    |
| `get`     | `GET`       | `/api/resource/:id`      | `params: { id }`                    |
| `create`  | `POST`      | `/api/resource`          | `payload: create`                   |
| `update`  | `PATCH`     | `/api/resource/:id`      | `params: { id }`, `payload: update` |
| `delete`  | `DELETE`    | `/api/resource/:id`      | `params: { id }`                    |
| `count`   | `POST`      | `/api/resource/count`    | `payload: filter`                   |
| `exists`  | `POST`      | `/api/resource/exists`   | `payload: filter`                   |

## Client SDK (`@brickkit/client`)

| Export                             | Kind     | Description                                                                             |
| :--------------------------------- | :------- | :-------------------------------------------------------------------------------------- |
| `createClient(api, options)`       | Function | Instantiates a synchronous Promise-based client returning `{ client, ready, dispose }`. |
| `createEffectClient(api, options)` | Function | Instantiates an Effect-native client returning Effects (`HttpApiClient.make`).          |

## CLI Commands (`@brickkit/cli`)

| Command             | Usage                                         | Description                                                               |
| :------------------ | :-------------------------------------------- | :------------------------------------------------------------------------ |
| `brick dev`         | `brick dev [entry] [--port <number>]`         | Starts development server with live reload and route banners.             |
| `brick start`       | `brick start [entry] [--port <number>]`       | Starts production server without file system watching.                    |
| `brick build`       | `brick build <entry> [--outdir <dir>]`        | Bundles a `Brick.app` into a Bun server bundle and emits `brick-ir.json`. |
| `brick gen openapi` | `brick gen openapi <entry> [--output <file>]` | Extracts OpenAPI 3.1 JSON specification from services.                    |
| `brick gen client`  | `brick gen client <entry> [--output <file>]`  | Generates a verified typed client contract file (`_brick/contract.ts`).   |
| `brick info`        | `brick info <entry>`                          | Exports the runtime service graph and route metadata as JSON.             |
| `brick migrate`     | `brick migrate`                               | Runs database migrations.                                                 |
