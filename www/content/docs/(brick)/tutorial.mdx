This tutorial walks through building a complete blog API featuring database models, CRUD resources, context layers, authorization policies, and custom business actions using Effect-native Brick-TS.

<Steps>

### Step 1: Project Setup and Dependencies

Initialize a Bun project and install the Brick-TS packages and Effect:

```bash
mkdir blog-api && cd blog-api
bun init -y
bun add @brickkit/core @brickkit/crud @brickkit/cli effect drizzle-orm
```

### Step 2: Define Database Models

Declare tables for articles and comments using Drizzle schema builders in `src/schema.ts`:

```ts title="src/schema.ts"
import { integer, sqliteTable, text } from "drizzle-orm/sqlite-core";

export const articles = sqliteTable("articles", {
  id: text("id")
    .primaryKey()
    .$defaultFn(() => crypto.randomUUID()),
  title: text("title").notNull(),
  slug: text("slug").notNull().unique(),
  body: text("body").notNull(),
  authorId: text("author_id").notNull(),
  views: integer("views").default(0).notNull(),
});

export const comments = sqliteTable("comments", {
  id: text("id")
    .primaryKey()
    .$defaultFn(() => crypto.randomUUID()),
  targetId: text("target_id").notNull(),
  authorId: text("author_id").notNull(),
  body: text("body").notNull(),
});
```

### Step 3: Configure Database Layer

Create `src/db.ts` to manage the database connection using `@brickkit/crud`'s `database` helper:

```ts title="src/db.ts"
import { database } from "@brickkit/crud";
import { drizzle } from "drizzle-orm/libsql";
import { Effect } from "effect";

export interface BlogDatabase {}
export const { Service: BlogDb, layer: DatabaseLive } =
  database<BlogDatabase>()(
    "BlogDb",
    Effect.sync(() => drizzle({ connection: ":memory:" })),
  );
```

### Step 4: Define CRUD Resources & Field Policies

In Brick-TS, database tables are exposed through declarative CRUD contracts with deny-by-default field policies. Create `src/articles.ts`:

```ts title="src/articles.ts"
import { Brick } from "@brickkit/core";
import { crudContract, sqliteStore } from "@brickkit/crud";
import { NotFound, Unauthorized } from "@brickkit/core/contracts";
import { Effect, Schema } from "effect";
import { eq, sql } from "drizzle-orm";
import { articles } from "./schema";
import { BlogDb } from "./db";

export const articleContract = crudContract({
  name: "article",
  path: "/api/article",
  table: articles,
  id: "id",
  errors: [NotFound, Unauthorized],
  fields: {
    id: { read: true, filter: ["eq", "in"] },
    title: {
      read: true,
      create: true,
      update: true,
      filter: ["eq", "contains"],
      sort: true,
    },
    slug: {
      read: true,
      create: true,
      filter: ["eq"],
      sort: true,
    },
    body: { read: true, create: true, update: true },
    authorId: { read: true, filter: ["eq"] },
    views: { read: true, sort: true },
  },
});

export const articleCrudActions = articleContract.implement({
  store: sqliteStore(articles, BlogDb),
  access: "public",
  hooks: {
    beforeCreate: ({ data }) =>
      Effect.succeed({
        ...data,
        id: crypto.randomUUID(),
        authorId: "usr_author",
        views: 0,
      }),
  },
});
```

### Step 5: Add Custom Business Actions

Add custom business logic that goes beyond standard CRUD operations. For example, incrementing the view count of an article:

```ts title="src/actions.ts"
import { Brick } from "@brickkit/core";
import { NotFound } from "@brickkit/core/contracts";
import { Effect, Schema } from "effect";
import { eq, sql } from "drizzle-orm";
import { articles } from "./schema";
import { BlogDb } from "./db";

const IncrementViews = Brick.action(
  "incrementViews",
  "/api/articles/incrementViews",
  {
    input: Schema.Struct({ id: Schema.String }),
    output: Schema.Struct({ id: Schema.String, views: Schema.Number }),
    errors: [NotFound],
  },
);

export const incrementViews = IncrementViews(({ id }) =>
  Effect.gen(function* () {
    const db = yield* BlogDb;
    const [updated] = yield* Effect.tryPromise(() =>
      db
        .update(articles)
        .set({ views: sql`${articles.views} + 1` })
        .where(eq(articles.id, id))
        .returning(),
    );
    if (!updated) {
      return yield* Effect.fail(new NotFound({ message: "Article not found" }));
    }
    return { id: updated.id, views: updated.views };
  }),
);
```

### Step 6: Assemble the Service and Application

Combine CRUD actions and custom actions into an immutable service in `src/app.ts`:

```ts title="src/app.ts"
import { Brick } from "@brickkit/core";
import { articleCrudActions } from "./articles";
import { incrementViews } from "./actions";
import { DatabaseLive } from "./db";

export const blogService = Brick.service("blog", {
  actions: {
    ...articleCrudActions,
    incrementViews,
  },
});

export default Brick.app({
  services: [blogService],
  layer: DatabaseLive,
  docs: { path: "/reference" },
});
```


### Create an Article

```bash
curl -X POST http://localhost:4000/api/article \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Getting Started with Brick-TS",
    "slug": "getting-started-with-brick",
    "body": "Brick-TS provides an Effect-native foundation for modern backends."
  }'
```

Response:

```json
{
  "id": "e379b38c-8f19-485a-a71c-3b91ef5246a4",
  "title": "Getting Started with Brick-TS",
  "slug": "getting-started-with-brick",
  "body": "Brick-TS provides an Effect-native foundation for modern backends.",
  "authorId": "usr_author",
  "views": 0
}
```


```bash
curl -X DELETE http://localhost:4000/api/article/e379b38c-8f19-485a-a71c-3b91ef5246a4
```

### List Articles with Filtering

Query articles using the type-safe filter schema:

```bash
curl -X POST http://localhost:4000/api/article/query \
  -H "Content-Type: application/json" \
  -d '{
    "where": {
      "field": "title",
      "op": "contains",
      "value": "Brick"
    },
    "orderBy": [{ "field": "title", "direction": "asc" }],
    "limit": 10
  }'
```

### Call the Custom Action

Invoke custom business logic directly:

```bash
curl -X POST http://localhost:4000/api/articles/incrementViews \
  -H "Content-Type: application/json" \
  -d '{"id": "e379b38c-8f19-485a-a71c-3b91ef5246a4"}'
```

Response:

```json
{
  "id": "e379b38c-8f19-485a-a71c-3b91ef5246a4",
  "views": 1
}
```
