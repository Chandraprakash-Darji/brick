---
title: Contracts and generation
description: Keep runtime schemas in a shared contract module.
---

The native client generator re-exports a schema-only HttpApi. It does not
reconstruct schemas from JSON or erase tagged error classes.

Set `client: { module: "./contract", exportName: "Api" }` on `Brick.app`. The
module path is relative to the server entry. It must be a separate file and its
OpenAPI paths and components must match the app.

```sh
brick gen client src/app.ts --output src/generated.ts
brick gen openapi src/app.ts --output openapi.json
```

The generated client module exports `api`, `createClient`, `createEffectClient`,
and an `AppClient` type. See [typed clients](/docs/typed-client) for a complete
contract module and browser call.
