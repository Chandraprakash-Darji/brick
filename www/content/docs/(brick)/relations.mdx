Brick-TS leverages standard relational database patterns and Drizzle ORM to model relations without proprietary abstractions or hidden query overhead.

## Minimal Example: One-to-Many Relationships

Model parent entities and related records using standard foreign keys and `@brickkit/crud` contracts:

```ts title="src/services/blog.ts"
import { Brick } from "@brickkit/core";
import { crudContract, sqliteStore } from "@brickkit/crud";
import { sqliteTable, text } from "drizzle-orm/sqlite-core";
import { BlogDb } from "./db";

// 1. Parent table: Articles
export const articles = sqliteTable("articles", {
  id: text("id")
    .primaryKey()
    .$defaultFn(() => crypto.randomUUID()),
  title: text("title").notNull(),
});

// 2. Child table: Comments (pointing to article via targetId)
export const comments = sqliteTable("comments", {
  id: text("id")
    .primaryKey()
    .$defaultFn(() => crypto.randomUUID()),
  targetId: text("target_id").notNull(),
  body: text("body").notNull(),
});

// 3. Declare CRUD contracts for both tables
export const articleContract = crudContract({
  name: "article",
  path: "/api/article",
  table: articles,
  id: "id",
  errors: [],
  fields: {
    id: { read: true, filter: ["eq", "in"] },
    title: { read: true, create: true },
  },
});

export const commentContract = crudContract({
  name: "comment",
  path: "/api/comment",
  table: comments,
  id: "id",
  errors: [],
  fields: {
    id: { read: true },
    targetId: { read: true, create: true, filter: ["eq"] },
    body: { read: true, create: true },
  },
});

// 4. Implement actions
export const articleActions = articleContract.implement({
  store: sqliteStore(articles, BlogDb),
  access: "public",
});

export const commentActions = commentContract.implement({
  store: sqliteStore(comments, BlogDb),
  access: "public",
});

export const blogService = Brick.service("blog", {
  actions: { ...articleActions, ...commentActions },
});
```

## Querying Related Child Records

Because `commentContract` enables `filter: ["eq"]` on `targetId`, clients can query all comments for an article via `POST /api/comment/query`:

```bash
curl -X POST http://localhost:4000/api/comment/query \
  -H "Content-Type: application/json" \
  -d '{
    "where": {
      "field": "targetId",
      "op": "eq",
      "value": "art_123"
    }
  }'
```

## Relational Joins in Custom Actions

When you need an aggregated response that combines parent and child records into a single payload, write a custom `Brick.action` using Drizzle's `leftJoin`:

```ts title="src/actions/getArticleWithComments.ts"
import { Brick } from "@brickkit/core";
import { NotFound } from "@brickkit/core/contracts";
import { Effect, Schema } from "effect";
import { eq } from "drizzle-orm";
import { articles, comments } from "../schema";
import { BlogDb } from "../db";

const ArticleWithComments = Brick.action(
  "getArticleWithComments",
  "/api/articles/details",
  {
    input: Schema.Struct({ id: Schema.String }),
    output: Schema.Struct({
      id: Schema.String,
      title: Schema.String,
      comments: Schema.Array(
        Schema.Struct({
          id: Schema.String,
          body: Schema.String,
        }),
      ),
    }),
    errors: [NotFound],
  },
);

export const getArticleWithComments = ArticleWithComments(({ id }) =>
  Effect.gen(function* () {
    const db = yield* BlogDb;

    const rows = yield* Effect.tryPromise(() =>
      db
        .select({
          articleId: articles.id,
          title: articles.title,
          commentId: comments.id,
          commentBody: comments.body,
        })
        .from(articles)
        .leftJoin(comments, eq(comments.targetId, articles.id))
        .where(eq(articles.id, id)),
    );

    if (rows.length === 0) {
      return yield* Effect.fail(new NotFound({ message: "Article not found" }));
    }

    const first = rows[0];
    const commentsList = rows
      .filter((r) => r.commentId !== null)
      .map((r) => ({ id: r.commentId!, body: r.commentBody! }));

    return {
      id: first.articleId,
      title: first.title,
      comments: commentsList,
    };
  }),
);
```

## Many-to-Many Relationships (Junction Tables)

For many-to-many associations (such as Articles and Tags), declare a junction table:

```ts title="src/schema/tags.ts"
import { sqliteTable, text, primaryKey } from "drizzle-orm/sqlite-core";

export const tags = sqliteTable("tags", {
  id: text("id").primaryKey(),
  name: text("name").notNull(),
});

export const articleTags = sqliteTable(
  "article_tags",
  {
    articleId: text("article_id").notNull(),
    tagId: text("tag_id").notNull(),
  },
  (t) => ({
    pk: primaryKey({ columns: [t.articleId, t.tagId] }),
  }),
);
```

## Relational Transactions

To perform atomic updates across multiple tables, use the store's `transaction` method or Drizzle's `$client.withTransaction`:

```ts
import { Effect } from "effect";

export const createArticleWithTags = (data: {
  title: string;
  tagIds: string[];
}) =>
  Effect.gen(function* () {
    const db = yield* BlogDb;
    return yield* db.$client.withTransaction(
      Effect.gen(function* () {
        const [article] = yield* db
          .insert(articles)
          .values({ title: data.title })
          .returning();
        for (const tagId of data.tagIds) {
          yield* db
            .insert(articleTags)
            .values({ articleId: article.id, tagId });
        }
        return article;
      }),
    );
  });
```
