### Schema

This is the example table in [Database Management & Migrations](/docs/database). `syncSchema` creates your declared tables; it does not add framework columns.

export const usersSchemaFields = [
  {
    name: "id",
    type: "text",
    description: "Row identifier.",
    isPrimaryKey: true,
    defaultValue: "crypto.randomUUID() (application)",
  },
  {
    name: "email",
    type: "text",
    description: "Unique email address.",
    isUnique: true,
  },
];
