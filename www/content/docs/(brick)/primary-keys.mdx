---
title: Primary keys
description: Use actual columns and database defaults
---

Pass `id: table.name` for a Frappe-style string key or `id: table.id` for a numeric
key. The column must belong to the resource table. When omitted, core infers a
single primary key; missing or ambiguous identifiers fail declaration.

CRUD input selectors consistently use `{id}` even when the stored column has a
different name. Updates separate `{id,data}`. The identifier cannot be updated.
Database-generated identifiers and `$defaultFn` values remain database concerns;
CRUD does not generate a prefixed string ID automatically.

```ts
const tickets = sqliteTable("tickets", {
  number: integer("number").primaryKey({ autoIncrement: true }),
  title: text("title").notNull(),
});
const ticket = service
  .resource({ name: "ticket", table: tickets, id: tickets.number })
  .use(
    crud({
      fields: {
        number: { read: true },
        title: { read: true, create: true, update: true },
      },
    }),
  );
await ticket.get({ input: { id: 42 } });
```

This fragment uses `sqliteTable`, `integer`, and `text` from core, `crud` from
`@brickkit/crud`, and an application's configured `service`.
