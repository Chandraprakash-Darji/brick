title: Brick-TS
description: Services, actions, and optional CRUD plugins
---

Define typed services and actions with `@brickkit/core`. Attach optional
capabilities through service and resource plugins. `@brickkit/crud` provides
field-controlled reads and writes; `@brickkit/cli` serves and compiles actions.

```ts
import {
  defineDatabase,
  defineService,
  sqliteTable,
  text,
} from "@brickkit/core";
import { crud } from "@brickkit/crud";

const pages = sqliteTable("pages", {
  id: text("id")
    .primaryKey()
    .$defaultFn(() => crypto.randomUUID()),
  title: text("title").notNull(),
  email: text("email"),
  internalNotes: text("internal_notes"),
});
const database = defineDatabase({ tables: { pages } });
const service = defineService("pages", { database });
const page = service.resource({ name: "page", table: pages, id: pages.id }).use(
  crud({
    fields: {
      id: { read: true, filter: ["eq", "in"] },
      title: {
        read: true,
        create: true,
        update: true,
        filter: ["eq", "contains"],
        sort: true,
      },
      email: {
        read: true,
        create: true,
        update: true,
        scrub: ({ value }) =>
          value === null ? null : value.replace(/^(.).*(@.*)$/, "$1***$2"),
      },
    },
  }),
);
```
