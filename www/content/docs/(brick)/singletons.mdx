In Brick-TS, singleton configuration rows are enforced using standard database uniqueness constraints and retrieved via `findOne`.

Please see the canonical guide: **[Relational Data Modeling & Joins](/docs/relations)**.

### Schema

These columns match the singleton example in [Relational Data Modeling & Joins](/docs/relations). The unique discriminator rejects duplicate values, but the application must keep it at `1` to maintain one row.

export const app_settingsSchemaFields = [
  {
    name: "id",
    type: "text",
    description: "Row identifier.",
    isPrimaryKey: true,
    defaultValue: "global_settings (application)",
  },
  {
    name: "singleton_key",
    type: "integer",
    description: "Singleton discriminator.",
    isUnique: true,
    isOptional: true,
    defaultValue: 1,
  },
  {
    name: "site_name",
    type: "text",
    description: "Site display name.",
  },
  {
    name: "maintenanceMode",
    type: "boolean",
    description: "Whether maintenance mode is enabled.",
    isOptional: true,
    defaultValue: false,
  },
];
