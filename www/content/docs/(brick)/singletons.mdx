---
title: Singleton records
description: Model singleton constraints in the database
---

Use database uniqueness constraints to express one record per application or
owner. CRUD does not infer singleton behavior from names. Install CRUD with
explicit field policies and use `findOne` for lookup, which returns null when no
record matches. Configure trusted access scopes for per-user records.

A unique constraint remains necessary when concurrent requests create rows.
A before-create lookup alone cannot enforce uniqueness. More specialized
singleton behavior can be packaged as a resource plugin.
