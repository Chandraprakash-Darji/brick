---
title: Input validation
description: Validate external values before calling a local handler.
---

Action validation belongs to its Effect Schema. Add schema checks for
structural constraints and use typed handler failures for business rules.

```ts
const Title = Schema.String.check(Schema.isMinLength(1));
```

Native HTTP validates the input and output schemas. A direct handler call
assumes decoded input. Use `Schema.decodeUnknownEffect(schema)(value)` when a
local caller receives an unknown value from a file, message, or other boundary.

For database write normalization, use an Effect-returning
[before hook](/docs/hooks). The native API does not have a separate `validate`
hook that changes a handler's inferred input type.
