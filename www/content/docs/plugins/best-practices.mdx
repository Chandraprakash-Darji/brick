---
title: Plugin best practices
description: Explicit tables, policies, names, and lifecycle
---

Keep schemas and migrations under application control. Plugins register
capabilities synchronously before build and do not open connections or mutate
schema during setup. Use resource plugins for behavior attached to a table.

Configure CRUD fields explicitly. Hidden fields are not selectable by callers;
masking is a separate output transformation. Use operation authorization and
trusted row scope for local and HTTP access. Custom routes need their own policies.

Use stable plugin and route names. Reuse the exact descriptor to reinstall on
one host. A different descriptor with the same name on that host fails; the same
descriptor on separate resources creates independent instances.

Test real local and HTTP calls, disabled routes, app prefix overrides,
collisions, multiple hosts, failed-installation rollback, and inferred APIs.
