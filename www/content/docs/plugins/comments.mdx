The `examples/extensions` package in the Brick repository contains a complete, production-ready extension implementing a page comments system.

## Extension Architecture

The comments extension is organized into three files:

```text
src/extensions/comments/
├── schema.ts       # Drizzle table definition
├── contract.ts     # Schema contracts and tagged errors
└── index.ts        # Action implementation factory
```

### 1. Database Schema (`schema.ts`)

```ts title="examples/extensions/src/extensions/comments/schema.ts"
import { sqliteTable, text } from "drizzle-orm/sqlite-core";

export const pages = sqliteTable("pages", {
  id: text("id").primaryKey(),
  title: text("title").notNull(),
});

export const commentsTable = sqliteTable("page_comments", {
  id: text("id")
    .primaryKey()
    .$defaultFn(() => crypto.randomUUID()),
  targetId: text("target_id").notNull(),
  body: text("body").notNull(),
});
```

### 2. Browser-Safe Contract (`contract.ts`)

Declares tagged error schemas and the CRUD contract. This module is browser-safe and can be imported by frontend clients:

```ts title="examples/extensions/src/extensions/comments/contract.ts"
import { crudContract } from "@brickkit/crud";
import { Schema } from "effect";
import { commentsTable } from "./schema";

export class InvalidComment extends Schema.TaggedError<InvalidComment>()(
  "InvalidComment",
  { message: Schema.String },
  { httpApiStatus: 400 },
) {}

export class MissingTarget extends Schema.TaggedError<MissingTarget>()(
  "MissingTarget",
  { message: Schema.String },
  { httpApiStatus: 404 },
) {}

export const Comments = crudContract({
  name: "pageComment",
  path: "/api/pageComment",
  table: commentsTable,
  id: "id",
  errors: [InvalidComment, MissingTarget],
  fields: {
    id: { read: true, filter: ["eq"] },
    targetId: { read: true, create: true, filter: ["eq"] },
    body: { read: true, create: true, update: true, filter: ["contains"] },
  },
});
```

### 3. Implementation Factory (`index.ts`)

The factory function `comments()` binds the contract to the database store, verifies that the parent page exists, and sanitizes comment text:

```ts title="examples/extensions/src/extensions/comments/index.ts"
import { sqliteStore } from "@brickkit/crud";
import { Effect } from "effect";
import { eq } from "drizzle-orm";
import { Database } from "../../database";
import { commentsTable, pages } from "./schema";
import { Comments, InvalidComment, MissingTarget } from "./contract";

export function comments() {
  return Comments.implement({
    store: sqliteStore(commentsTable, Database.Service),
    access: "public",
    hooks: {
      beforeCreate: ({ data }) =>
        Effect.gen(function* () {
          const body = data.body.trim();
          if (!body) {
            return yield* Effect.fail(
              new InvalidComment({ message: "Comment body cannot be blank" }),
            );
          }

          const db = yield* Database.Service;
          const [parent] = yield* db
            .select({ id: pages.id })
            .from(pages)
            .where(eq(pages.id, data.targetId))
            .limit(1)
            .pipe(Effect.orDie);

          if (!parent) {
            return yield* Effect.fail(
              new MissingTarget({ message: "Comment target not found" }),
            );
          }

          return { ...data, body };
        }),

      beforeUpdate: ({ data }) => {
        if (data.body === undefined) return Effect.succeed(data);
        const body = data.body.trim();
        return body
          ? Effect.succeed({ ...data, body })
          : Effect.fail(
              new InvalidComment({ message: "Comment body cannot be blank" }),
            );
      },
    },
  });
}
```

## Running the Example

Run the extension example from the repository root:

```bash
bun run --cwd examples/extensions demo
```

To start the HTTP server on port 3001:

```bash
bun run --cwd examples/extensions serve
```

Test creating a comment via curl:

```bash
curl -X POST http://localhost:3001/api/pageComment \
  -H "Content-Type: application/json" \
  -d '{"targetId": "page-1", "body": "Great article!"}'
```
