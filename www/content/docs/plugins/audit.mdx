---
title: Audit Hooks
description: Write audit logs and history rows within database transactions.
---

An audit extension intercepts CRUD write operations using `afterCreate`, `afterUpdate`, and `afterDelete` hooks, saving audit records in the same database transaction.

## Minimal Example

Create an audit logging hook that records actor ID, action name, and modified rows:

```ts title="src/extensions/audit.ts"
import { sqliteTable, text } from "drizzle-orm/sqlite-core";
import { Effect } from "effect";
import { BlogDb } from "../db";

export const auditLogs = sqliteTable("audit_logs", {
  id: text("id").primaryKey(),
  entity: text("entity").notNull(),
  entityId: text("entity_id").notNull(),
  action: text("action").notNull(),
  timestamp: text("timestamp").notNull(),
});

export const auditHooks = {
  afterCreate: ({ row }: { row: { id: string } }) =>
    Effect.gen(function* () {
      const db = yield* BlogDb;
      yield* Effect.tryPromise(() =>
        db.insert(auditLogs).values({
          id: crypto.randomUUID(),
          entity: "article",
          entityId: row.id,
          action: "create",
          timestamp: new Date().toISOString(),
        }),
      );
    }),

  afterDelete: ({ id }: { id: string }) =>
    Effect.gen(function* () {
      const db = yield* BlogDb;
      yield* Effect.tryPromise(() =>
        db.insert(auditLogs).values({
          id: crypto.randomUUID(),
          entity: "article",
          entityId: id,
          action: "delete",
          timestamp: new Date().toISOString(),
        }),
      );
    }),
};
```

## Attaching to a CRUD Contract

Attach the audit hooks when implementing your contract:

```ts title="src/services/articles.ts"
export const articleActions = articleContract.implement({
  store: sqliteStore(articlesTable, BlogDb),
  access: "public",
  hooks: auditHooks,
});
```

## Transaction Guarantees

Because `@brickkit/crud` store operations execute within database transactions, if an audit hook fails, the mutation transaction rolls back, preventing unlogged writes from persisting.
