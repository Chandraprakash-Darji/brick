Brick-TS measures performance metrics on pushes to `main` that touch packages, benchmarks, example applications, dependencies, or TypeScript configuration (docs/website-only changes do not trigger) across macOS, Linux, and Windows runners, publishing results directly to the repository's `benchmarks` branch.

## What Is Measured

The automated benchmark suite evaluates:

- **Actions and Resource CRUD**: Compiled HTTP request throughput (req/sec) and p99 latency under concurrency.
- **Server Startup**: Build, listen, and first-request timing across 10, 100, and 1,000 actions, plus cold process launch latency for minimal servers.
- **Idle CPU & Memory**: Server process RSS, net heap delta, and idle CPU time over five-second idle windows.
- **Bundle Size**: Minified bundle size (raw and gzip bytes) for production servers, including bundled dependencies.
- **Runtime Micro-benchmarks**: Context creation, TypeBox schema validation, dispatch overhead, and prepared statement reuse.
- **Database Backends**: SQLite in-memory and file performance, plus PostgreSQL CRUD operations against isolated test databases.

## Running Benchmarks Locally

Run smoke tests or full benchmark suites directly from the repository root:

```bash
# Run quick micro-benchmarks
bun run bench:micro

# Run full smoke suite
bun run bench:smoke

# Run HTTP route benchmarks
bun run bench:http

# Run database benchmarks
bun run bench:prepared
bun run bench:postgres
```

CI invokes the runner with `--rounds 3 --requests 500 --compiler-requests 10000` (routine runs) or `--rounds 6 --requests 2000 --compiler-requests 50000` (manual full runs). The external `oha` HTTP load generator is used only for the compiler suite; the `http`/`postgres` suites run closed-loop in-process. To capture a local snapshot in the same format CI merges:

```bash
bun bench/ci.ts run --rounds 1 --oha $(which oha) --out .build/benchmark-snapshot.json
```

For detailed load generator configuration and measurement guidelines, consult the repository's [bench/README.md](https://github.com/Chandraprakash-Darji/brick/blob/main/bench/README.md).
